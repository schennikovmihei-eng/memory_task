# Memory Management

Демонстрационная программа для исследования управления виртуальной и физической памятью в операционных системах **Linux** и **Windows**, с акцентом на механизм **ленивого выделения памяти (Lazy Allocation)**.

---

## Цель проекта

Наглядно показать различия в поведении виртуальной и физической памяти при динамическом выделении и освобождении, а также продемонстрировать работу стратегии **ленивого выделения** в современных ОС.

---

## Возможности программы

- Интерактивное управление блоками памяти

- Мониторинг выделенной виртуальной и физической памяти в реальном времени

- Кросс‑платформенная работа (Linux/Windows)

- Наглядная визуализация состояния памяти

- Поддержка различных стратегий выделения памяти

---

## Теоретическая справка

- Программа демонстрирует ключевые концепции управления памятью:

- Виртуальная память — адресное пространство, выделяемое процессу ОС

- Физическая память — реальная оперативная память (RAM)

- Ленивое выделение (Copy-on-Write) — память физически выделяется только при реальной записи

- Страничная организация — память делится на страницы (обычно 4 KB)

### Общее для обеих ОС:
- Используется стратегия отложенного выделения

- Виртуальная память резервируется немедленно

- Физическая память выделяется только при фактической записи

- Освобождение памяти уменьшает оба показателя
